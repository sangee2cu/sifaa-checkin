SIFAA QR Scanner

Scan a member QR code to return the member ID to event check-in.

Tap Start camera and allow camera access when your browser asks.

If the check-in app does not update automatically, copy this ID, return to the check-in tab, and paste it into the Member ID field.

Open Google Apps Script
